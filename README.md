# 媒介伊蚊消杀配药计算器

面向登革热、基孔肯雅热等媒介伊蚊防制工作的配药辅助工具。项目将药物登记信息、适用场景和器械参数放在同一套规则中校验，尽量避免把“可搜索到的药物”误当成“可直接用于计算的药物”。

## 主要功能

- 按药品名称、登记证号或有效成分搜索药物
- 超低容量空间喷雾、室内小空间喷雾和滞留喷洒计算
- 支持复配制剂、按有效成分反算及自定义药物
- 对登记状态、有效期、使用场景、剂量维度和器械参数进行计算前检查
- 浏览登记药物、器械资料及本机计算历史
- 纯前端静态导出，不上传用户输入或计算历史

药物“可搜索”不代表“可计算”。只有登记资料、剂量单位和适用场景均满足规则的记录才会进入正式计算；资料不完整的药物仍可展示，但会明确提示不能直接计算。

## 本地运行

需要 Node.js 20.9 或更高版本。

```bash
npm ci
npm run dev
```

打开 <http://localhost:3000/mosquito/>。

## 完整检查

```bash
npm run check
```

该命令依次执行代码规范检查、TypeScript 类型检查、单元测试、生产构建和静态导出路径检查。生产文件输出到 `out/`。

## 部署说明

项目使用 Next.js 静态导出，固定基础路径为 `/mosquito`。部署时应让 `out/` 的内容在站点的 `/mosquito/` 路径下提供；如需改为其他路径，请同步修改 `next.config.ts`、`public/manifest.json` 和静态导出检查脚本。

## 数据维护

- 登记药物主数据：`src/data/drugs.json`
- 常用登记药物补充数据：`src/data/common-drugs-icama.ts`
- 器械数据：`src/data/machines.json`
- 计算准入及核验规则：`src/services/data.ts`、`src/verification/`
- 计算引擎：`src/calculation-engine/`

新增药物时必须保留原始登记来源，并分别核对有效成分、剂型、防治对象、施用方法、剂量单位和登记有效期。无法确认的剂量单位不得通过猜测转换为可计算数据。

## 使用提示

本工具用于现场作业前的辅助核算，不能替代农药登记标签、产品说明书、当地主管部门技术方案或专业人员判断。实际用药应以当前有效的官方登记标签和现场要求为准。
